# SmartWatch Website

## 📌 About the Project

SmartWatch is a responsive product website developed to showcase a modern smartwatch and its features. It provides information about the watch, including its specifications, features, and price, using HTML, CSS, and JavaScript.

## ✨ Features

- Attractive and user-friendly interface.
- Displays smartwatch features and specifications.
- Responsive website design.
- Theme toggle functionality.
- Order form for customers.
- Shop opening and closing status.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

You can view the live project here:

**Live Demo:** https://maria2354.github.io/smart_watch-/

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in your web browser.
4. The SmartWatch website will open.
